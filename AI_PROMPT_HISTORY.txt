AI PROMPT HISTORY — MANDATORY

If you use ANY AI tool during the assessment, you must submit the COMPLETE prompt history for EVERY AI tool used for this specific assessment project.

The AI prompt history must be submitted inside the Git repository as a separate text file.

Required file:

AI_PROMPT_HISTORY.txt

The file must contain:

- Every prompt, question, instruction, or request sent to AI for this specific assessment project
- Prompts from every AI tool used for this specific assessment project
- All prompts in the exact order they were sent
- No omitted prompts
- No rewritten prompts
- No combined prompts
- No summarized prompts

The AI prompt history must only include prompts related to this assessment project. Do not include prompts from unrelated projects, previous work, personal conversations, or other tasks.

The AI_PROMPT_HISTORY.txt file must be committed and included in the submitted Git repository.

If you used multiple AI tools, include the complete prompt history from every AI tool in the same AI_PROMPT_HISTORY.txt file, maintaining the original chronological order.

If possible, you may also provide an exported/shared conversation link accessible without login. However, the AI_PROMPT_HISTORY.txt file inside the submitted Git repository is mandatory.

If you did not use AI, create the AI_PROMPT_HISTORY.txt file and write:

"N/A — I did not use AI tools."
